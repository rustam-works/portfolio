Privacy Policy

Pinterest MCP client — a personal API integration

Last updated: 18 October 2026

This policy covers the private software client operated by Rustam Mushraipov (“the application”) that connects to the Pinterest API over the Model Context Protocol (MCP). The application is a personal tool. It is not offered to the public, has no other users, and is used solely by its operator to manage his own Pinterest account.

Who is responsible

Rustam Mushraipov, independent art director and designer, acting as an individual. Contact: rustam.mushraipov@gmail.com.

What data the application accesses

Using an OAuth access token granted by the operator for his own Pinterest account, the application may read and modify:

  • boards, board sections, and their titles and descriptions;
  • pins, including their images, titles, descriptions, and destination links;
  • basic account profile information returned by the Pinterest API.

The application does not access data belonging to any other Pinterest user, and it does not collect data from visitors to this website.

Why the data is used

Solely to organise the operator's own Pinterest boards: sorting pins, creating and renaming boards and sections, moving pins between them, and removing duplicates.

Storage and retention

The application runs locally on the operator's own computer. It has no server component and no database. Data retrieved from the Pinterest API is held in memory for the duration of a task, and any temporary working files are deleted once that task is complete. The OAuth access token is stored locally on the operator's computer and is never published or committed to any repository.

Sharing with third parties

No data is sold, rented, or shared with third parties for advertising, analytics, or any other purpose. Pinterest content may be passed to an AI assistant used by the operator strictly to carry out the organising task described above, and is not used to train any model.

Security

Access is limited to the minimum OAuth scopes needed to read and organise boards and pins. Credentials are kept on the operator's own computer. The operator may revoke the application's access at any time from Pinterest account settings, which immediately ends all access.

Your rights

Because the application processes only the operator's own account data, there is no third-party personal data to access, correct, or erase. Any question about this policy can be sent to the address above and will be answered within 30 days.

Changes to this policy

If the application's behaviour changes, this page will be updated and the date at the top revised.
